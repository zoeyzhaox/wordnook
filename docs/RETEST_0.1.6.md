# 拾词 0.1.6-beta.1 复测手册

以下 42 项沿用[原审查编号](./UX_FIXES.md)。一次只测一行即可。浏览器可从此版本仓库下载 `Wordnook-preview.html`，用桌面版 Chrome 打开。打开「偏好设置」，记下底部版本。Apple 芯片 v0.1.5、Intel v0.1.4 均早于本次修改。测 Mac 原生行为请使用同版本源码或对应架构的同版本安装包。

标有「新记录」的项目请各自在新的浏览器测试配置中开始，初始应有 120 个内置词、每天 10 个新词、0 积分。测试版中打分、导入和恢复都会改变学习记录，请只用测试数据。同一行内要求刷新或重开时，继续用该行原来的配置和文件路径。日期、计数以设备本地时间为准。

想直接运行测试时，在仓库根目录使用 Node.js 22.12 或更新版本。首次准备环境用以下命令。界面测试会自动启动本地服务，启动前请关闭已占用 5173 端口的其他项目。

```sh
npm ci
npx playwright install chromium
npm run build
```

需要手动导入测试词表时，下列命令会在系统临时目录生成文件，最后打印文件夹位置。例句与译文均为功能测试占位内容。各文件供独立测试使用。

```sh
node --input-type=module <<'NODE'
import {mkdtempSync, writeFileSync} from 'node:fs';
import {tmpdir} from 'node:os';
import {join} from 'node:path';
const dir = mkdtempSync(join(tmpdir(), 'wordnook-retest-'));
const row = word => ({word, meaning:'测试释义 '+word, phrase:word+' today',
  phraseZh:'搭配示例', example:word+' today.', exampleZh:'例句示例。'});
const save = (name, data) => writeFileSync(join(dir,name+'.json'), JSON.stringify(data));
const many = Array.from({length:5001}, (_,i) => row('lemma'+[2,1,0]
  .map(n => String.fromCharCode(97 + Math.floor(i/26**n)%26)).join('')));
save('5000',many.slice(0,5000));
save('plus-one',many.slice(5000));
save('over-limit',many);
save('luminous',[row('luminous')]);
save('two',[row('luminous'),row('noteworthy')]);
save('spelling',['I','self-aware',"can't"].map(row));
save('errors',[row('luminous'),{...row('typo'),exampleZh:'',example:'x'.repeat(1007)}]);
save('art-bad',[{...row('art'),phrase:'artificial light'}]);
save('art-good',[{...row('art'),phrase:'art class'}]);
console.log(dir);
NODE
```

**Mac 故障恢复演练（37）**。从前一节的隔离测试实例做一次学习，在偏好设置把备份导出到方便选择的位置，再从菜单栏退出。以下命令另建一个全新目录并写入两份刻意损坏的测试文件。选择上一步导出的备份用于恢复。若需重开，用相同的 `wordnook_recovery_dir` 再运行最后一条命令。

