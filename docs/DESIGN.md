# v0.1.1 设计修订

用户明确否定了 v0.1.0 的整体风格与配色。因此这次重做页面结构、字体、颜色职责和文案，不保留原来的奶油白 / 橄榄绿 / 衬线大标题方向。

| 页面 | 这次实现 |
| --- | --- |
| 今日 | 紧凑工具栏、学习计数、左侧可选队列、右侧词汇详情 |
| 单词卡 | 去掉纸张容器与宣传标题；单词、搭配、例句和评分按阅读顺序排列 |
| 小游戏 | 两个练习入口按行排列；局部颜色区分选择与拼写；移除山景 |
| 词库 | 密度更高的搜索列表，释义与搭配直接可见 |
| 奖励 | 积分余额及兑换清单，券与配色样本是商品预览 |
| 偏好 | 标准标签 / 控件行，不附加情绪化文案 |
| 悬浮窗 | 中性标题栏，英文单词突出，主要操作使用蓝色 |

选中和主操作采用蓝色，成功与失败保留独立语义色。原来已解锁的 forest 主题数据仍兼容，现在对应青绿强调色，不改变整页背景。

完整可复用提示词与研究链接见 `UI_BRIEF.md`。研究指南对原有暖色编辑式模板的批评与这次用户反馈一致，但不将任何配色视为客观上“AI”或“非 AI”。是否合适仍由用户实际体验判断。
