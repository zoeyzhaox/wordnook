# 验证记录

## v0.1.6-beta.1 · 2026-11-22

本版源码通过了 28 项 Node.js 核心与存储测试，以及 33 项 Chromium 界面测试。复测覆盖了累计导入 5,001 个词后重开、跨词库完成每日任务、两标签页同步、游戏结算和损坏记录恢复。另用本地单文件预览断网启动，完成评分、刷新、打开小窗和开始游戏。[本版变更](../CHANGELOG.md) · [复测环境、步骤与结果](RETEST_0.1.6.md)

原生小窗拖动后的定位、macOS 原生备份恢复对话框，以及已安装程序的版本和芯片架构显示，仍需在真实 Mac 上验收。本版发布范围为源码与网页预览。已有 Mac 下载分别是 Apple 芯片 v0.1.5 和 Intel v0.1.4。[安装与运行](../README.md)

## v0.1.4 历史记录

以下记录保留该版本当时的测试范围和发布状态。


- 核心测试覆盖 120 词唯一性、搭配完整性、FSRS、每日限额、重复奖励、复活、导入、备份与磁盘恢复；新增词库切换共享进度、贴纸及配色权限、旧备份兼容。
