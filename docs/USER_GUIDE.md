# 拾词 Wordnook 使用手册

适用版本：0.1.4 测试版。

## 1. 安装与第一次打开

桌面版适用于 macOS 12 或更新版本。在苹果菜单的「关于本机」查看芯片：M 系列选择 `Wordnook-AppleSilicon.zip`，Intel 选择 `Wordnook-Intel.zip`。解压，将 `Wordnook.app` 拖入「应用程序」，再打开。

当前安装包尚未经过 Apple 开发者签名、公证，也尚未完成 Mac 实机验收。如果系统阻止打开，请保留错误提示以便反馈，不要关闭系统安全保护。Windows 暂无已验收的安装包。

想先体验界面，可以下载 `Wordnook-preview.html` 并用浏览器打开。网页预览无法跨应用置顶或开机启动，网页与桌面版的数据也各自独立。

首次使用：选择托福、雅思或自定义词库，查看「今天」的学习任务，按默认每天 10 个新词开始。内置共有 120 个基础词条，托福和雅思各 100 个、重合 80 个；不是完整考试必备词库。

## 2. 桌面悬浮窗

在「偏好设置」选择屏幕角落、显示器和透明度。安装版可启用「登录 Mac 后自动开启」；此开关默认关闭。关闭主窗口后应用仍可留在菜单栏，彻底退出请用菜单栏入口。

拖动原生小窗边缘调整尺寸，尺寸会自动保存。网页小窗预览请拖动右下角，也可选「极简／释义／完整」尺寸。

| 空间大小 | 显示内容 |
| --- | --- |
| 最小 | 英文、✓ 会、✕ 不会 |
| 稍大 | 增加中文释义、前后导航 |
| 更大 | 增加发音、搭配、英文例句、详细评分 |
| 足够大 | 再显示例句翻译 |

小窗跟随系统浅色或深色外观。先点击小窗使其获得键盘焦点，再用 ← / → 查看前一个或后一个词。切换单词不等于完成学习；点击「会／不会」才记录回忆结果。全局快捷键 ⌘⇧W 用于显示或隐藏小窗。

## 3. 单词卡与复习

看见英文后，先回忆含义，再按空格翻面，按 1–4 或点击按钮评价「忘记／费劲／记得／轻松」。按真实掌握情况选择，忘记后再次出现是正常复习过程。

应用使用 FSRS 间隔复习，根据每次回忆调整下次出现时间，并非对所有单词套用一张固定遗忘曲线表。默认目标保持率 90%，不是效果保证。只看小窗、朗读或浏览词库不会提高掌握记录。

## 4. 发音

在偏好设置选择英语声音、英美口音并试听。应用使用系统语音，没有附带独立语音包；希望离线朗读时，请先在系统中安装英语声音。无声音时先检查系统音量、声音选择及试听结果。

## 5. 五种小游戏

| 游戏 | 操作 |
| --- | --- |
| 词义选择 | 选择英文对应的中文，答后查看正确答案和例句 |
| 三轮拼写 | 第一轮补最后 1–2 个字母，第二轮看首字母输入剩余部分，第三轮完整拼写 |
| 单词飞行 | 按提示找目标，拖动或左右键移动飞机，空格发射；错误命中扣机会，超时结束 |
| 词汇垂钓 | 移动鱼钩，对准与提示对应的小鱼下钩 |
| 记忆配对 | 每次翻两张，配对英文与中文；未配对时点「盖回去」再试，依次挑战 4／8／12 张 |

计时游戏在离开页面或窗口失焦时暂停，返回后手动继续。游戏当前局不跨应用重启保存。答错后可看答案再记忆；三连对有动画反馈，在设置中可减少动画。拼写前两轮是提示练习，第三轮独立回忆才可正式更新复习；记忆配对不将记住位置视为掌握词义。

## 6. 积分与兑换

| 项目 | 积分 |
| --- | ---: |
| 完成每日学习任务 | 6，每天一次 |
| 前两局合格游戏 | 每局 2 |
| 每天新获得积分上限 | 10 |
| 复活券 | 8 |
| 配色 | 20–30 |
| 贴纸 | 10–15 |
| 每张壁纸 | 100 |

单张词卡、连击、配对小关不单独发积分。合格游戏需完整结束、至少 4 题且正确率至少 50%；记忆配对需完成本轮全部关卡且至少 2 对。每天完成学习任务和两局合格游戏，从零开始、不兑换其他物品，10 天能攒够一张壁纸。中断一天不清空已得积分，旧余额和已兑换奖励保留。

每日学习任务在当天第一次正式作答时固定，包含当时到期词和当日新词配额；每个目标至少成功回忆一次。修改词库或新词上限不会重置任务，需要回到原词库完成剩余目标。没有学习目标的当天不会自动获得学习积分。

在奖励页面兑换配色和贴纸后按界面操作使用；壁纸解锁后可下载 3840×2160 PNG，再自行设为桌面壁纸。应用不会自动替换你的系统壁纸。

## 7. 导入自己的单词

在偏好设置下载模板，填写后在词库点击「导入词表」。支持 UTF-8 CSV 和 JSON；每批最多 5,000 词、20 MB。必填字段如下：

| 字段 | 示例 |
| --- | --- |
| word | clarify |
| meaning | 澄清；阐明 |
| phrase | clarify a point |
| phraseZh | 阐明一个观点 |
| example | Could you clarify this point? |
| exampleZh | 你能阐明这一点吗？ |

`pos`（词性）和 `topic`（主题）可选。搭配应包含所填单词原形。JSON 可使用词条数组或 `{ "words": [...] }`。已有单词按忽略大小写去重；任一词条不合法会拒绝整批，请根据报错修改后重试。公开分享词库时只分享有权再分发的内容。

## 8. 备份、更新与问题反馈

在偏好设置导出 JSON 备份，保存词库、进度、收藏、复习历史及奖励。更新前建议先备份。恢复备份会替换当前进度，需要在界面确认；不会更改当前系统登录项设置。

桌面学习数据保存在本机，无账号同步。浏览器清理站点数据可能丢失网页进度，不建议使用无痕模式长期学习。应用无遥测、无远程 AI 请求。

反馈问题时请提供：应用版本、macOS 版本、Apple／Intel 芯片、发生步骤、错误提示或截图。截图与备份可能包含自己的学习内容，请先检查再公开提交。

若小窗不见了，先用 ⌘⇧W 或菜单栏显示小窗，再检查所选显示器。若方向键无效，先点击小窗获得焦点。若没有获得游戏积分，检查本局是否合格以及当天是否已经获得两次奖励。
