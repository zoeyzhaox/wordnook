# 词库、发音和贴纸（0.1.2）

内置 120 个唯一词条；托福与雅思各 100 个，其中共同学术基础 80 个、方向补充各 20 个。所有中文释义、搭配翻译及例句在项目内编写；未复制商业词库。词库只是基础选词，不承诺出现频率、考试覆盖率，也不冒充官方必备词表。公开大规模词库前须做语言校对、许可证审查、重复及变形词归并。本版保留用户导入 CSV / JSON 的入口、模板和完整数据校验。

雅思方向补充城市、环境、教育、健康及技术；托福方向补充地学、生物、考古、校园及物理。共用词以稳定 ID 存储，切换词库不重复发奖。每日新词总上限跨词库共享。

发音调用 Web Speech / 操作系统语音，不含第三方录音或独立语音模型。声音列表可能异步加载；界面监听 voiceschanged 并支持刷新。优先匹配用户选择，其次口音和本地服务；界面显示实际声音和语言，无法匹配时不假称选定口音已加载。是否本地根据服务提供的 localService 标志标注；实际出声及离线能力仍需在 Mac 验收。

Mac 可在系统设置的辅助功能中管理和下载声音：
https://support.apple.com/en-mo/guide/mac-help/mchlp2290/mac
