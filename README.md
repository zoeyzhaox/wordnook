# 拾词 Wordnook

一个安静的桌面背词小应用：在屏幕角落顺手记一个词，也可以打开完整窗口，认真复习或玩一小局。

**状态：0.1.4 公开测试版。Mac 安装包尚未完成实机验收、Apple 开发者签名和公证。**

## 安装前必读：需要手动允许首次打开

**当前发布未签名、未公证的免费 Mac 测试版。首次打开可能出现“Apple 无法验证 Wordnook”的提示。** 这不是下载失败，也不代表 Apple 已确认应用安全。

如果确认安装包来自本仓库并愿意试用：先尝试打开一次，点击提示中的「完成」，再进入 **系统设置 → 隐私与安全性 → 仍要打开**，按提示验证身份并确认。无需关闭系统整体安全保护或运行绕过检查的终端命令。若报错是“将损坏电脑”“检测到恶意软件”或“已损坏”，请停止并反馈，不要套用此步骤。

[中文使用手册：首次打开的完整步骤](docs/USER_GUIDE.md) · [Apple 官方说明](https://support.apple.com/zh-cn/102445)

使用手册还包含小窗、游戏、积分、导入与备份说明。

## 现在有什么

- Electron 原生独立悬浮窗：四角定位、选择显示器、透明度、跨桌面显示、15 分钟暂隐、自动换词和暂停。
- Mac 菜单栏入口，`⌘⇧W` 显示 / 隐藏。关闭主窗口后继续留在菜单栏；通过菜单栏彻底退出。
- 安装版可在偏好设置启用登录后启动。为尊重用户系统设置，默认关闭。
- 主动回忆单词卡：空格翻面，1–4 记录「忘记 / 费劲 / 记得 / 轻松」。
- FSRS-6 调度，目标保持率 90%，学习阶段 1 分钟 / 10 分钟，之后按卡片状态安排间隔，最长 365 天。
- 五种小游戏，包含三轮提示拼写和不限尝试的记忆配对；具体计分和复习规则见游戏说明。
- 奖励闭环：每日学习任务 +6，前两局合格游戏各 +2；复活券 8 分，配色 20–30 分，贴纸 10–15 分，壁纸 100 分。
- 120 个原创学习词条（托福与雅思各 100 个，重合 80 个），全部有中文释义、常用搭配、中英例句。不是 ETS 官方词表，不是完整托福词库。
- UTF-8 CSV / JSON 导入，收藏、主题筛选、搜索，完整 JSON 备份 / 恢复。
- 无账户、无遥测、无远程 AI 请求。学习内容离线使用。朗读依赖系统语音；离线使用请先安装英语声音。

## 在 Mac 使用

提供 Apple 芯片（arm64）和 Intel（x64）两个 ZIP 构建，系统要求 macOS 12 或更新版本。解压后将 `Wordnook.app` 放进「应用程序」。

这些构建尚未完成签名 / 公证，且未在真实 Mac 运行验证，macOS 可能阻止启动；不要将它们当作正式发行版。“无法验证”提示的手动允许步骤见本页顶部与使用手册；“已损坏”或明确恶意软件提示应保留内容用于排查。最可复现的开发运行方式是在自己的 Mac 从以下源码命令启动。

打开后进入「偏好设置」选择角落，并在安装版中打开「登录 Mac 后自动开启」。Mac 系统设置也可以禁用登录项；应用内开关不能覆盖系统策略。跨全屏空间、菜单栏与多显示器位置需在你的实际桌面配置上确认。

## 从源码运行

需要 Node.js 22 或更新版本与 npm。依赖版本由 lockfile 固定。

```sh
npm ci
npm start
```

`npm start` 先构建本地界面，再启动桌面程序。开发运行不注册登录项；请使用打包安装版测试开机启动。

另外提供 `Wordnook-preview.html`，下载后可在浏览器直接打开体验，无需安装依赖。它不能实现跨应用置顶；预览数据与桌面版独立。

仅预览界面：`npm run dev`，访问终端给出的 localhost 地址。浏览器模式保存到本地浏览器存储，与桌面学习记录相互独立；它不能实现跨应用置顶或开机启动。浏览器内的小窗使用同一套组件，可直接预览四角位置，不再依赖弹出窗口。

构建：

```sh
npm run package:mac
# 备用 Windows 构建配置，尚未在 Windows 验收
npm run package:win
```

当前选择分发未签名测试版，由用户了解提示后自行决定是否允许打开。若未来采用 Developer ID 签名及公证，使用 `scripts/release-mac-signed.mjs`，前提和验证范围见 `docs/MAC_RELEASE.md`；该脚本不会改变现有未签名安装包，也不会自动发布 Release。

## 导入词表

在词库点击「导入词表」，或在偏好设置下载模板。必填字段：

| 字段 | 内容 |
| --- | --- |
| word | 单词原形，如 `clarify` |
| meaning | 中文释义 |
| phrase | 包含该原形的搭配，如 `clarify a point` |
| phraseZh | 搭配的中文 |
| example | 英文例句 |
| exampleZh | 例句的中文 |
| pos | 可选词性 |
| topic | 可选主题 |

每批最多 5,000 个词，文件最多 20 MB。已有单词按不区分大小写的文本去重。任何词条不合法都会拒绝整批，不会只写入一部分。JSON 可以是词条数组或 `{ "words": [...] }`。不要导入未经授权的商业词典或培训机构内容来公开再分发。

## 记忆与奖励规则

悬浮展示、朗读、查看词库都不改变掌握程度。翻面后评价才是正式学习。游戏选择题答对按 Hard 记录，拼写题答对按 Good 记录，答错按 Again 记录。游戏提前练习未到期的词不改动正式复习时间。FSRS 默认参数没有经过你的个人历史训练；90% 是目标，不是效果保证。

新词默认每天最多 10 个，到期复习不限。奖励不惩罚忘记，也不会因为今天中断而清空。对同一个词重复点击、双窗口同时操作不能额外发奖。复活不会改变错误学习记录。奖励仅用于个人激励，不具有现金价值，也不设计在线防作弊系统。

## 数据与隐私

Mac 数据位于 Electron 的 userData 目录，通常是 `~/Library/Application Support/Wordnook/learning.json`（具体目录可随应用名称变化）。每次变更先写临时文件并 fsync，再原子替换，同时保留上一版 `.bak`。主文件损坏时会保留损坏副本并尝试恢复上一版；恢复会提示最近一次操作可能丢失。

手动导出的 JSON 包含词库、进度、收藏、复习历史及奖励。恢复会替换现有进度，需要在界面二次确认；当前系统登录项偏好保持不变。游戏当前局不会跨应用重启或备份恢复保留，但已记录的学习和奖励保留。浏览器数据若被清除或在无痕模式使用，不保证持久。

应用不请求麦克风、不读取你的其他文件。系统语音可能使用已安装的本地声音或系统提供的其他声音，本应用不上传例句到自建服务。

```sh

```

核心测试覆盖调度、每日上限、重复提交、奖励、复活、导入、恢复和落盘故障恢复。UI 测试覆盖学习、窗口同步、筛选收藏、两种游戏、兑换、设置和导入。详细验收记录见 `docs/VALIDATION.md`。

## 设计与代码

- `src/core.js`：纯状态事务、FSRS 调度、奖励、游戏规则与导入校验。
- `electron/store.js`：单一权威状态和原子落盘，避免多窗口覆盖。
- `electron/main.js` / `preload.cjs`：窗口、系统集成、有限 IPC 接口；渲染器不开 Node，启用 context isolation 和 sandbox。
- `src/app.js` / `style.css`：学习、游戏、词库与偏好设置。
- `src/words.js`：可审阅的起步词库。
- `docs/DESIGN.md`：真实参考、界面取舍与后续验收。
